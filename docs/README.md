# BharatRx Documentation Hub (`docs/`)

## 📌 Directory Purpose
This directory contains central project documentation, architecture specifications, API contracts, data schemas, and development guidelines for the BharatRx team.

---

## 📚 Documentation Index

1. **Architecture Specifications**: High-level system design, sequence diagrams, and component interactions.
2. **API Contracts**: RESTful / JSON payload specifications between `backend` and `modules/` (`consultation`, `prescription_rag`, `safety_engine`).
3. **Integration Specifications**: Data formats exchanged during pre-consultation intake, OCR parsing, and safety evaluation.
4. **Data Schemas**: Standardized JSON schemas for patient profiles, prescription extractions, and risk severity reports.
5. **Team Development Notes**: Workflow tips, environment setup instructions, and hackathon roadmap updates.

---

## 📝 Document Guidelines
When adding new documentation files to this folder, please use clear markdown formatting and standard naming conventions (e.g., `api_contracts.md`, `architecture_overview.md`, `data_schemas.md`).
