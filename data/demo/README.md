# Synthetic Demo & Test Data (`data/demo/`)

## 📌 Directory Purpose
This directory is reserved for mock, synthetic patient profiles, sample prescription images, and sample datasets created specifically for hackathon testing and feature demonstrations.

---

## ⚠️ Important Compliance & Data Guidelines

> [!CAUTION]
> **ABSOLUTELY NO REAL PATIENT DATA (PHI / PII)**  
> Never store or commit real patient health information (PHI), personally identifiable information (PII), or actual medical records in this directory or anywhere in the repository. All test datasets must be 100% synthetic, artificial, and generated solely for hackathon validation.

---

## 🗂️ Planned Structure
- `patients/`: Synthetic patient profiles (JSON) with mock history, allergies, and vitals.
- `prescriptions/`: Sample mock prescription images for testing OCR and RAG extraction pipelines.
- `scenarios/`: Test case scenarios representing low, moderate, and high safety alert conditions.
