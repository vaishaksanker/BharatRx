# Medical Reference Data (`data/medical/`)

## 📌 Directory Purpose
This directory is reserved for local medical reference datasets, pharmacological lookup tables, drug interaction databases, and knowledge base schemas utilized by the RAG (`modules/prescription_rag/`) and Safety Engine (`modules/safety_engine/`) systems.

---

## ⚠️ Important Compliance & Data Guidelines

> [!WARNING]
> **NO COPYRIGHTED OR SENSITIVE MEDICAL DATA**  
> Do not commit proprietary, copyrighted, or non-public medical datasets to this repository. All knowledge bases integrated here must use open-access datasets, standardized open medical coding schemes (e.g., RxNorm, ICD-10, SNOMED CT), or synthetically structured reference tables.

---

## 🗂️ Planned Structure
- `schemas/`: Data definitions for drug interactions, contraindications, and drug classes.
- `reference/`: Permissible open reference tables and lookup maps.
